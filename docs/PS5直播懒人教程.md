# PS5 直播推流 · 完整教程

> **两条路线，本教程都适用：**
> - 🖱️ **图形界面版（推荐）** —— 直接运行 `release\PS5直播推流助手.exe`，全流程在界面里点按完成，见项目 README 的「快速开始」一节。
> - ⌨️ **命令行版** —— 双击 `source\` 下的 `①一键启动.bat` 等脚本，下文「二、每次开播：固定 5 步」即按此写法。
>
> 两条路线的**原理、五关自检、PS5 的 DNS 填法与排障方法完全一致**，区别只是操作入口。

> 目标：不用采集卡、不用 Remote Play，把 PS5 画面经电脑推到你的 RTMP 后台（再由后台接入抖音 / B站）。
> 建议网络方式：**PS5 和电脑连同一个家用路由器（局域网模式）**，PS5 不需要直连电脑。

---

## 〇、30 秒看懂原理

```
PS5 ──网线/WiFi──> 同一个路由器 <──WiFi── 电脑(192.168.1.100)
                     │                          │
            普通上网(PSN/游戏)走AK加速    Twitch推流域名被"DNS劫持"到电脑
                                                │
                                          电脑接住画面(MediaMTX)
                                                │
                                          ffmpeg转推 → 你的RTMP后台
```
一句话：**让 PS5 以为 Twitch 的推流服务器就是你电脑，于是把直播画面发到电脑，电脑再转发出去。**

## 一、只做一次的准备

### 1. PS5 绑定一次 Twitch（以下使用AK加速器作为例子）
1. PS5 进游戏 → 按**创建键** → 直播 → 选 **Twitch**
2. 屏幕出现 6 位绑定码
3. 电脑加速后浏览器打开 `twitch.tv/activate`，输入绑定码并登录，提示成功即可

### 2. 填推流目标
打开工具文件夹里的 **`推流配置.txt`**，在 `自定义推流地址=` 后面粘贴你 RTMP 后台给的**一整串地址**（必须 `rtmp://` 开头），保存。
- `网关IP=` 留空（自动检测）、`上游DNS=自动`（自动测速，换加速器也不怕）

### 3. PS5 网络设置（最关键，只改一个地方）

**第 1 步｜物理连接**：PS5 用网线或 WiFi 连到**路由器**（和电脑同一个路由器），**不是插到电脑上**。电脑先开 AK 的主机/局域网加速。

**第 2 步｜拿到"该填的 DNS"**：在电脑双击一次 **`①一键启动.bat`**（UAC 弹窗点"是"）。在标题为 `PS5-DNS-Server` 的黑色英文窗口里找到这一行：

```
>>> Set PS5 PRIMARY DNS = 192.168.1.100
```
**等号后面这个 IP，就是你要填到 PS5 上的"首选 DNS"。** 它就是你电脑的局域网 IP（你当前是 `192.168.1.100`，换网络后可能变，以窗口实时显示为准）。看完先双击 **`③一键停止.bat`** 关掉。

**第 3 步｜在 PS5 上填**：设置 → 网络 → 设置互联网连接 → 选中当前网络 → 高级设置 → **手动**，按下表填：

| PS5 项目 | 填什么 |
|---|---|
| IP 地址 | **照抄 AK 给的，不动** |
| 子网掩码 | **照抄 AK 给的，不动** |
| 默认网关 | **照抄 AK 给的，不动** |
| **首选 DNS** | **填第 2 步那个 IP（`192.168.1.100`），不要填 AK 给的 DNS** |
| 备选 DNS | **留空**（填 0.0.0.0 或不填） |

> 记法：**AK 给的 4 项里，前 3 项（IP/掩码/网关）照抄，唯独"首选 DNS"换成电脑 IP，备选清空。**

*（备用）不打开脚本也能查电脑 IP：电脑按 `Win+R` 输入 `cmd` 回车，输入 `ipconfig` 回车，找"无线局域网适配器 WLAN"下的 `IPv4 地址`。*

#### 换了加速器、参数叫法不一样怎么办？（通用识别法）
不管哪个加速器、给的网段/数字是什么，PS5 手动设置里就 5 个空，**只有"首选 DNS"归我们改，其余全部按加速器说的填**：

| PS5 / 加速器里的字段（各种叫法） | 特征 / 例子 | 怎么办 |
|---|---|---|
| IP 地址 / 地址 / IP Address | 如 192.168.x.x、10.x、172.27.x.x | **照抄**加速器给的（或按它要求选"自动"） |
| 子网掩码 / 掩码 / Subnet / Netmask | 一定是 `255.255.x.x` 开头 | **照抄** |
| 默认网关 / 网关 / 路由器 / Gateway | 通常和 IP 同网段、.1/.254 结尾 | **照抄** |
| **首选 DNS / 主 DNS / DNS1 / 域名服务器** | 加速器常给 8.8.8.1、1.1.1.1 等 | **不填它给的**，改填工具窗口 `PRIMARY DNS` 那行的 IP |
| **备选 DNS / 次 DNS / DNS2** | 加速器常给第二个 DNS | **留空** |
| MTU / 代理 | — | 保持"自动/不使用代理"，不用动 |

**三个永远成立的判断：**
1. 名字里带 **DNS / 域名 / Name Server** 的，才是我们要接管的——首选填工具窗口的 IP，备选清空；加速器给的任何 DNS 数字都**不要**填（程序内部会自动选最快的上游）。
2. 名字里带 **IP / 掩码 / 网关 / Mask / Gateway** 的，一律照抄，它们负责让 PS5 走进加速通道，每个加速器不同，不能自己改。
3. **首选 DNS 到底填几，永远看工具窗口那行 `>>> Set PS5 PRIMARY DNS = x.x.x.x`，不要自己拿"网关"去套。** 程序会按当前网络/加速器自动算出正确值：
   - 局域网模式（PS5 和电脑同路由器，你现在这种）：这个值=电脑局域网 IP，换加速器通常不变，换 WiFi/路由器才可能变；
   - 直连模式（PS5 网线直连电脑）：这个值=加速器虚拟网段 IP，换加速器会变——所以更要以窗口为准。

> 若某加速器让 PS5"IP 自动获取、只改 DNS"，那就 IP/掩码/网关选**自动**，只把 DNS 设成手动、首选填窗口 IP、备选空，道理完全一样。
> 填完一定做"测试互联网连接"：取得 IP 和互联网连接都成功才算对；失败多半是首选 DNS 误填成了网关/加速器 DNS，或备选没清空。

## 二、每次开播：固定 5 步

```
① 电脑开 AK 主机加速（和平时一样）
② 双击 ①一键启动.bat（UAC 点"是"），弹出的黑窗口都不要关
③ PS5 进游戏 → 创建键 → 直播 → Twitch → 开始直播
④ 双击 ④监看画面.bat，浏览器自动打开 MediaMTX 自带播放页、看到游戏画面 = 电脑已收到
⑤ 双击 ②转推RTMP后台.bat，去你的 RTMP 后台确认有画面（延迟约10~30秒）
```
结束：先在 PS5 上停止 Twitch 直播，再双击 **`③一键停止.bat`**。

## 三、怎么确定"弄成功了"？——过 5 关，一关一关来

**每过一关再做下一关；哪一关不过，就停在那关看第五节排查，不用往下走。**

### ✅ 第 1 关：电脑两个服务起来了
双击①后会有两个黑窗口：
- **MediaMTX 窗口**：出现 `listener opened on :1935`
- **PS5-DNS-Server 英文窗口**：依次出现
  - `[OK] ... resolved ...`（上游可用，至少一行）
  - `>>> Set PS5 PRIMARY DNS = 192.168.1.100`
  - 最后一行 `[OK] Listening on 0.0.0.0:53` ← **看到它才算就绪**
- ①自己的窗口里防火墙三条都是 `[OK]`

### ✅ 第 2 关：PS5 改完 DNS 后"不断网"
PS5：设置 → 网络 → **测试互联网连接**。
- "取得 IP 地址"**成功**、"互联网连接"**成功** → 过
- 若失败/断网 → 看第五节第 1 条

### ✅ 第 3 关：劫持真的发生了
PS5 对 Twitch 点"开始直播"后，**立刻看英文 DNS 窗口**，应刷出：
```
[HIJACK] xxxx.live-video.net (A) -> 192.168.1.100
```
出现 `[HIJACK]` = PS5 的推流已被引到电脑。**没有这行 = 没劫持到，停在这里排查。**

### ✅ 第 4 关：画面到电脑了
- **MediaMTX 窗口**出现 `path app/一长串 is ready`
- 双击 **`④监看画面.bat`**，浏览器打开 MediaMTX 自带播放页、出现游戏画面（约 1 秒）。黑屏就改双击 **`④监看(兼容模式).bat`**

#### MediaMTX 自带网页怎么手动进（它没有"总控台首页"）
MediaMTX 不提供控制面板首页（直接开 `8888/8889` 根地址是 404，正常）。它自带的是"状态接口 + 每路流的播放页"，地址规律如下（把 `流名` 换成实际的 `app/xxxx`）：

1. **查流名**：浏览器开 `http://127.0.0.1:9997/v3/paths/list`，在 JSON 里找 `"name":"app/xxxx"`，这就是流名（PS5 开播后才会出现）
2. **WebRTC 播放页（低延迟，约1秒）**：`http://127.0.0.1:8889/流名/`（末尾斜杠要带）
3. **HLS 播放页（兼容、慢几秒最稳）**：`http://127.0.0.1:8888/流名/`
4. **给 OBS / 直播伴侣当"网络流素材"用的地址（不是网页，是流）**：
   - RTMP：`rtmp://127.0.0.1:1935/流名`
   - HLS：`http://127.0.0.1:8888/流名/index.m3u8`
   - ⚠️ 不要把第 2/3 条的**网页地址**填进直播伴侣（WebRTC 网页抓不到会黑屏），要填本条这种**流地址**

> 播放页没声音：点页面里的**喇叭/音量图标**取消静音（浏览器默认拦截自动播放声音），或改用 8888 的 HLS 页。
> **不想手动拼地址**：双击 `④监看画面.bat`（兼容模式用另一个④），它会自动查到流名、打开播放页，并在黑窗口里列出下面 4 个地址——**RTMP 拉流地址会自动复制到剪贴板**（到直播伴侣直接 Ctrl+V），4 个地址还会存一份到工具目录的 `stream_urls.txt`。窗口是英文，对照：
> - `WATCH IN BROWSER` = 浏览器观看页（WebRTC/HLS）
> - `PULL URLS` 下的 `RTMP`/`HLS` = 填进 OBS/直播伴侣的**流地址**
> - `copied to clipboard` = 已复制；黑屏就换 HLS 兼容模式那个④

### ✅ 第 5 关：成功推到后台
双击 **`②转推RTMP后台.bat`**：
- 窗口先显示"已捕获 PS5 本地流"，然后 ffmpeg 的 `frame=` 数字**一直往上涨** = 正在推
- 去你的 RTMP 后台看到画面，全部完成

## 四、英文 DNS 窗口逐行中文对照

| 英文行 | 含义 |
|---|---|
| `[MODE] LAN-ROUTER mode` | 识别为局域网模式（你的情况，正确） |
| `[MODE] DIRECT mode` | 识别为 PS5 直连电脑模式（你不是这个） |
| `[OK] 8.8.x.x 10ms resolved ...` | 该上游 DNS 可用（毫秒越小越快） |
| `[BAD] ...` | 这个上游不通，会自动跳过 |
| `[OK] Primary upstream: ...` | 已自动选定最快的上游 |
| `>>> Set PS5 PRIMARY DNS = x.x.x.x` | **★PS5 首选 DNS 就填这个** |
| `[OK] Listening on 0.0.0.0:53` | **服务已就绪，正在等 PS5** |
| `[HIJACK] xxx -> 192.168.1.100` | **正在劫持这路推流（开播时出现=成功）** |
| `[WARN] all upstreams failed` | 上游暂时全失败，正在重试 |
| `[FATAL] No upstream DNS works` | 上游全不通，PS5 会断网（见排查第1条） |
| `[FATAL] Cannot bind port 53` | 53 端口被占用（见排查第2条） |

## 五、出问题对照排查

| 现象 | 原因与解决 |
|---|---|
| **第2关：PS5 改 DNS 后断网/连不上互联网** | ①看英文窗口有没有 `[OK]...resolved` 和 `Listening`，若 `[FATAL] No upstream`：确认电脑自己能上网、AK 已加速，把配置 `上游DNS=自动` 改成 `上游DNS=8.8.8.1` 后重开①；②确认 PS5 首选 DNS 填的是窗口里的电脑 IP（192.168.1.100），**不是路由器地址 192.168.1.1，也不是 AK 的 8.8.8.1**；③备选 DNS 必须留空；④确认 PS5 和电脑连的是同一个路由器 |
| **英文窗口 `Cannot bind port 53`** | 53 端口被占（多半是 AK 的 DNS 接管）。先双击③停止，右键①以管理员身份运行；若仍报，截图发我，需要在 AK 里关闭它的 DNS 代理 |
| **第3关：开播后没有 `[HIJACK]` 行** | PS5 首选 DNS 没填对/没保存；或 PS5 没真正开始 Twitch 直播；回第 2 关确认 PS5 能上网 |
| **MediaMTX 没有 `is ready`、④监看黑屏** | 说明第3关没过，画面没到电脑，先解决劫持 |
| **转推窗口一直"还没收到 PS5 流"** | PS5 没开播，或没出现[HIJACK]，回到第3关 |
| **ffmpeg 在跑但后台黑屏** | 打开`推流配置.txt`，把 `重编码=否` 改成 `重编码=是`，保存后重新转推 |
| **换了加速器/换了 WiFi 后失效** | 电脑 IP 可能变了：重开①，看窗口新的 `PRIMARY DNS` 地址，把 PS5 首选 DNS 改成新值即可 |
| **窗口中文乱码（仅英文DNS窗口除外）** | 关掉该窗口重新双击对应 bat，不要直接双击 .py 文件；DNS 窗口已固定为英文不会乱码 |

## 六、文件清单与撤回

**命令行版文件（`source\` 目录）**
| 文件 | 作用 |
|---|---|
| `①一键启动.bat` | 开防火墙 + 启动 MediaMTX 和 DNS（要管理员） |
| `②转推RTMP后台.bat` | 把画面推到你配置里的自定义 RTMP 地址（主线） |
| `②转推抖音.bat` / `②转推B站.bat` | 直接推平台（备用） |
| `③一键停止.bat` | 停止全部服务 |
| `④监看画面.bat` / `④监看(兼容模式).bat` | 自动找流、打开自带播放页；并拼好 RTMP/HLS 拉流地址（RTMP 自动复制剪贴板，另存 `stream_urls.txt`） |
| `推流配置.txt` | 填推流地址、上游 DNS、是否重编码 |
| `一键撤回.bat` | 删除防火墙规则、还原所有改动（撤回后手尾干净） |

> 想彻底卸载：先双击`③一键停止`，再双击`一键撤回`，最后删掉整个工具文件夹即可，系统不留残留。

## 七、原理简图（了解即可）

```
PS5 ─(网线/WiFi)→ 同一路由器 ←(WiFi)─ 电脑 192.168.1.100
                     │                    │
          普通域名(PSN/游戏)        Twitch推流域名 *.live-video.net / live.twitch.tv
          转发上游、走AK加速         被DNS劫持 → 192.168.1.100
                                               │
                                    MediaMTX :1935 接住
                                               │
                                    ffmpeg → RTMP后台 → 抖音/B站
```
*有问题就盯两个窗口：英文 `PS5-DNS-Server` 看劫持、`MediaMTX` 看收流，它们会直接告诉你卡在哪一关。*
