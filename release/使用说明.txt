PS5 直播推流助手 · 使用说明
========================================

【这是什么】
把 PS5 的 Twitch 直播通过“DNS 劫持 → 本机 MediaMTX 收流 → ffmpeg 转推”的方式，
一键转发到抖音直播伴侣 / B站直播姬 / 自定义 RTMP 后台。无需采集卡、无需 Remote Play。

【文件结构（请勿拆开移动）】
  PS5直播推流助手.exe   主程序（双击运行，会请求管理员权限，点“是”）
  mediamtx\             收流服务（必须和 EXE 放在同一文件夹，勿删）
  推流配置.txt           各平台推流地址/推流码，也可在程序“设置”页填写
  PS5直播懒人教程.md     原理与详细排障说明（可选阅读）
  使用说明.txt           本文件

【环境要求】
  · Windows 10/11，电脑和 PS5 连同一个路由器（最好同一 Wi-Fi/有线）。
  · 电脑需安装 ffmpeg 并加入 PATH。若没有，程序会自动识别 winget 安装的 ffmpeg；
    也可把 ffmpeg.exe 放到本文件夹的 ffmpeg\ 子目录（即 ffmpeg\ffmpeg.exe）。

【开播五步】
  1. 双击 PS5直播推流助手.exe，弹出 UAC 点“是”（用于放行 53/1935 端口）。
  2. 打开主机加速器（如 UU/雷神），加速“PS5 主机”，记下加速器要求填写的 DNS IP；
     页面顶部会显示本机应填的 DNS 地址（如 192.168.1.100），点“复制 IP”。
  3. PS5：设置 → 网络 → 设定互联网网络 → 选当前网络 → 高级设置：
       首选 DNS：填上面复制的 IP；备选 DNS 留空（0.0.0.0）；
       IP / 子网掩码 / 网关照抄加速器；MTU 自动；代理不使用。
  4. 回到电脑点“一键启动”。顶部“开播 5 关检测”会逐关变绿：
       ①服务启动 ②上游网络 ③劫持成功 ④画面到达 ⑤转推成功。
     然后在 PS5 进游戏 → 创建键 → 直播 → Twitch → 开始直播；
     第 3 关变绿即劫持成功；可点“打开 WebRTC 监看”低延迟看画面（黑屏换 HLS）。
  5. 在“设置”页填好抖音/B站/后台的推流地址和推流码，点“开始转推”；
     第 5 关变绿后，去抖音直播伴侣 / B站直播姬点“开始直播”即可。

【监看声音怎么选】
  · WebRTC 监看：延迟最低（约 1 秒），但浏览器 WebRTC 不支持 PS5 的 AAC 音频，所以有画无声。
  · HLS 监看：原生支持 AAC、有声音，但延迟较高（约 3-8 秒），黑屏/要听声时用它。
  · 二者都只是“本地监看”，不影响转推到后台的画面与声音。

【出错怎么办】
  · 程序会在“总览”页用红色叉号标出卡在哪一关，并给出诊断卡，
    明确告诉你是【哪个设备 / 哪里】出的问题及处理方法（按可能性排序）。
  · 也可到“诊断”页点“一键前置体检”，逐项检查管理员、文件、ffmpeg、
    网卡、53/1935 端口占用、上游 DNS、推流配置。
  · “日志”页可按来源筛选并导出详细日志，方便定位。

【关闭 / 清理】
  · 点“一键停止”会关闭 MediaMTX、DNS 劫持和 ffmpeg；
    点“一键撤回”可移除自动添加的防火墙规则。
  · 直接关闭窗口会最小化到系统托盘；在托盘图标右键可退出。
  · 本程序为单文件封装，设置不进注册表；卸载直接删文件夹，
    再用“一键撤回”清理防火墙即可。

【提示】
  · 界面为极简风格（纯白 + 玻璃质感），默认「白天」纯白主题；
    右上角太阳/月亮图标可在「黑夜 / 白天」两套主题间切换，选择会自动记住，下次启动保持。
  · 顶部为导航栏：总览 / 监看 / 设置 / 诊断 / 日志；按住标题栏空白处拖动可移动窗口。
  · 启动时会先显示约 2 秒的启动动画，可拖动、点击任意处立即进入主界面；
    若动画长时间不消失，说明文件不完整，请确认 mediamtx 文件夹与 EXE 在同一目录。
  · 多个实例会争抢 53/1935 端口，程序已做单实例保护，重复双击只会唤醒已有窗口。
